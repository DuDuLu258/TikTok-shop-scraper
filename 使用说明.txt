========================================
TikTok Shop 美区「畅销商品」采集器 使用说明
========================================

【重要前提】
1. 必须使用"美国地区"的网络节点（VPN/代理），否则 TikTok 会判定地区不符。
2. 需要已安装 Google Chrome 或 Microsoft Edge。
3. 本版本使用 CDP 模式：程序不自己开浏览器，而是连接你手动启动的 Chrome，
   这样才能通过 TikTok 对首页的整页安全验证（自动化浏览器会被拦截）。

------------------------------------------------
一、文件夹里有什么（发给别人时整个文件夹一起发）
------------------------------------------------
TikTokRanking 文件夹
  ├─ TikTokRanking.exe   主程序（双击运行，图形界面）
  ├─ _internal\          依赖文件（千万别删、别单独移动 exe）
  ├─ 启动Chrome.bat      启动专用 Chrome（先双击它）
  └─ 使用说明.txt         本说明

注意：
· TikTokRanking.exe 必须和 _internal 文件夹、启动Chrome.bat 放在同一文件夹里，
  不能只复制 exe 一个文件走。
· 发给别人时，把整个 TikTokRanking 文件夹压缩成一个 zip 发过去即可。

------------------------------------------------
二、每次抓取的标准流程（三步）
------------------------------------------------
第 1 步：启动 Chrome
  1. 打开 TikTokRanking 文件夹。
  2. 双击「启动Chrome.bat」。
  3. 黑色窗口显示 [OK] Chrome started with debug port 9222. 后，
     会弹出一个新的 Chrome 窗口（独立配置，不影响你日常用的 Chrome）。
  4. 保持这个 Chrome 窗口开着（可以最小化），进行第 2 步。
  （如果显示 [OK] Port 9222 is already open，说明 Chrome 已在运行，直接第 2 步）

第 2 步：打开抓取程序
  双击「TikTokRanking.exe」，出现图形界面。

第 3 步：填写设置并开始抓取
  1. 类别：选「全部」= 总榜不过滤；选具体类别（如"美妆个护"）= 只保留该类别商品。
  2. 销量下限：留空不限；填 490000 表示只保留销量 ≥ 490,000 的商品。
  3. 上架时间：留空不限；填 30 表示只保留上架不超过 30 天的商品。
     ★ 使用上架时间筛选前，必须先把「Tiktok选品助手」插件安装到
       第 1 步启动的那个 Chrome 里（见下方「五、上架时间筛选说明」），
       否则程序读不到上架时间，设置筛选后所有商品都会被跳过。
  4. 抓取数量：默认 15 条，按需修改。
  5. 点「开始抓取」，程序自动进入每个商品详情页读取介绍并下载图片，
     完成后弹出输出文件夹。
  抓取结果保存在 exe 同目录的 output\ 文件夹：
      output\TikTok_US_Ranking.xlsx
     （新增了「商品上架时间」列；如果 Excel 正被打开占用，
       程序会自动另存为带时间戳的新文件）

------------------------------------------------
三、人机验证怎么处理
------------------------------------------------
1. 首次运行可能弹出滑块验证：用鼠标把拼图拖到缺口处即可。
   （这是真人 Chrome，正常拖动就能通过；验证状态会保存，下次通常不再弹）
2. 抓取过程中如果中途再次弹出验证：程序会自动停下等你，
   通过后程序自动继续，无需其它操作。
3. 如果验证明明通过、程序还在等：程序会等你手动确认后继续。

------------------------------------------------
四、常见问题
------------------------------------------------
Q1: 提示「无法连接 Chrome（http://127.0.0.1:9222）」
    → 说明 Chrome 没启动或窗口被关了。重新双击「启动Chrome.bat」。

Q2: 双击 bat 后提示 Chrome 没开调试端口
    → 说明上次的 Chrome 没退干净。把所有属于 .cdp_profile 的 Chrome
      窗口都关掉（任务管理器里结束多余的 chrome.exe），再重新双击 bat。

Q3: 页面整页显示 Security Check / 进不去
    → 确认用的是"美国地区"节点；确认是通过「启动Chrome.bat」启动的 Chrome，
      而不是自己随便打开的那个 Chrome。

Q4: 想中途停止
    → 图形界面里点「停止抓取」即可：程序会等当前步骤结束，然后保留
      已抓到的商品并正常导出（不会强制关窗口，避免导出半个 Excel）。
      停止后也可以再次点「开始抓取」重新跑。

Q5: 抓到的数量少于设定值
    → 可能首页该栏目已到底，或类别/销量过滤后符合条件的商品较少，属正常。
      可以多抓几次，每次商品会有所不同。

Q6: 换了电脑 / 换了网络节点后提示地区不符
    → 确认新网络是"美国地区"；如果仍不行，把 TikTokRanking 文件夹里的
      .cdp_profile 文件夹删除，再重新双击「启动Chrome.bat」重新验证一次。

------------------------------------------------
五、上架时间筛选说明
------------------------------------------------
背景：TikTok 官方页面不显示商品上架时间；本功能的数据来自 Chrome 插件
「Tiktok选品助手」（极鲸云，tiktokshuju.com）在商品详情页注入的
"商品预估上架时间"（第三方估算值，精确到秒，例如 2025-08-09 15:50:59）。

前提（必须做，否则筛不到）：
  1. 先双击「启动Chrome.bat」启动专用 Chrome（独立配置 .cdp_profile）。
  2. 在这个专用 Chrome 窗口里打开 https://chrome.google.com/webstore ，
     搜索并安装「Tiktok选品助手」（或先在日常 Chrome 里安装好，再用
     chrome://extensions 的「加载已解压的扩展程序」导入同一个插件文件夹）。
  3. 确认安装后：打开任意一个 TikTok Shop 商品详情页，页面右下角应出现
     该插件的浮层（显示商品ID/销量/上架时间等）。
  4. 之后正常使用即可。程序抓取每个商品详情页时，会自动读取浮层里的
     上架时间（精确值）写入 Excel 的「商品上架时间」列。

筛选规则：
  · GUI：填"上架 ≤ N 天"即只保留上架不超过 N 天的商品（留空不限）。
  · 命令行：--max-age-days N（上架 ≤ N 天）、--min-age-days N（上架 ≥ N 天），
    可组合成区间，如 --min-age-days 30 --max-age-days 180。
  · 设置了筛选但某商品详情页读不到上架时间（插件未装/浮层未出现）时，
    该商品会被跳过，并在日志里说明原因。

注意：
  · 插件注入的是"预估"上架时间，与真实上架时间可能有偏差，仅供选品参考。
  · 未安装插件时，Excel 的「商品上架时间」列会留空，不影响其它功能。
